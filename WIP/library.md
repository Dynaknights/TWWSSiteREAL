This is a small personal archive that I made to host writing, like a personal / slightly private alternative to Archive of Our Own. Included are two javascript files (one for Neocities, one for elsewhere) which can generate a table of contents automatically, and also link together any chapter files in the same way as AO3's previous and next chapter buttons.
            So long as you link the scripts and all that, you can retool this chapter system for any kinda site pretty quickly. There is also a glossary function. For example: I love cats and dogs and have a collection of daggers and swords.
